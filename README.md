# sdl-study2-host

Deployment-only repository for staff testing of a browser-based spring simulation (University of
Alabama research project). It contains **no source code, research data, scoring materials, keys or
participant information** — only a deployment workflow. The compiled browser build is attached to
releases and published with GitHub Pages.

Everything published here is **publicly reachable**. Study sessions can only be started with codes
issued by the research team; the server refuses all other codes.

Versioned builds are served at `https://<owner>.github.io/sdl-study2-host/<build>/`.
